  # Rainstorm Project - Stratosphere
<sub>(Very heavy work in progress.)</sub>

![Forks](https://img.shields.io/github/forks/FateUnix29/Stratosphere)
![Last commit](https://img.shields.io/github/last-commit/FateUnix29/Stratosphere)

Rainstorm is (planned to be) an open source roleplay(-survival?) game set in the worldbuilding project known as Nomen (latin for 'name'), inspired by the likes of Space Station 14.
Things are currently in a very early state, so no promises. Development is also very, very slow, and the upstream team is minuscule.
The current idea is that it should have an in-depth health and construction system.

Nomen's lore can be found on the [Discord](https://discord.gg/FYGrDjJJtt). **Please be respectful. Additionally, we can generally sniff out bad intentions.**

----

Stratosphere is the eternally in-progress game engine for the N.C.N.P. Rainstorm Project.
